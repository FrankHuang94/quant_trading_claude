# Firm profiles

> **TL;DR**
>
> - 18 short profiles of firms that shape quantitative trading in US equities, chosen for strategy relevance rather than size.
> - Each gives the firm's known strategy focus from public sources only, a snapshot table and a "Fact vs lore" section.
> - Check the confidence tag before repeating any figure: private firms' numbers usually come from unnamed sources.

**Level:** Core · **Read time:** ~3 min · **Last verified:** 2026-11

## What each profile covers

Each profile runs 300–500 words: what the firm does, its known strategy focus and approach, and a "Fact vs lore" section that separates sourced facts from stories that circulate in the industry. Strategy names link to the [module 02 dossiers](../../02-strategies/index.md), so a profile is a jumping-off point, not a destination.

## How to read the snapshot table

| Field | What it tells you |
|---|---|
| Type | the firm type from the [taxonomy](../taxonomy-of-quant-firms.md) |
| Scale | revenue, assets or headcount, with a date and a tag |
| Horizon | the holding periods the firm is known for |
| Known strategies | families with public evidence, linked to dossiers |
| Tech signals | public hints: engineering blogs, open-source code, hardware or compute deals |
| Confidence | overall reliability: higher when filings exist, lower when the profile rests on press reports |
| Sources | the number and kind of sources used |

Tags follow the KB convention: `[Verified]` primary source (filing, regulator, firm publication), `[Reported]` credible press, `[Estimate]` our derivation with reasoning shown, `[Lore]` widely repeated but unverified.

!!! warning "Public sources only"
    Profiles draw on filings, firm publications, regulator documents and reputable press. They contain no insider information, and strategy descriptions stay general because firms do not publish their models. Revenue figures for private firms come from unnamed sources and can be wrong. Firms change quickly, so check each profile's "Last verified" date.
